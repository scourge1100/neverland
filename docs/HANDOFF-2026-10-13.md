# Neverland 포트폴리오 작업 인수인계 (2026-10-13)

이 문서는 로컬 전용 메모입니다(커밋하지 않음). 다음 세션이 이 파일만 읽고 이어갈 수 있게 정리했습니다.

## 1. 사이트와 배포 구조

- 운영 주소: https://neverland.40.82.146.87.sslip.io (정적 백업: https://wonderful-cliff-01d049c00.7.azurestaticapps.net, 한국어 전용)
- 콘텐츠 원본은 **Outline(운영)**. `content/`의 Markdown은 업로드용 원본이자 Git 기록.
- 블로그 서버(`scripts/blog-server.mjs`)가 Outline의 `Portfolio` 컬렉션을 읽어 렌더링. 문서 안 `neverland-meta`(frontmatter)로 type/slug/lang 등을 구분. 캐시 약 60초.
- 사이트 코드(`config/site/*`, `scripts/*`, `.github/workflows/*`, `Dockerfile.blog`, `config/routes.Caddyfile`)를 main에 푸시하면 GitHub Actions가 VM에 배포(blog 재빌드 + Caddy reload). 정적 백업(Azure Static Web Apps)도 같이 배포.
- 공유 VM(`empire-server`)이라 **docker/containerd 관련 apt 설치·삭제 금지**(2026-08-18 장애). VM 명령은 `az vm run-command`가 자주 막히므로 막히면 사용자에게 명령을 넘길 것.

## 2. 작업 규칙 (사용자가 정한 것)

- **콘텐츠 문서는 Outline 업로드만** 한다. **커밋·푸시는 사용자가 "커밋 푸시해줘"라고 할 때만** 한다.
- 업로드 명령(Node 22 필요): `source ~/.nvm/nvm.sh; nvm use v22.14.0; OUTLINE_BASE_URL=https://neverland.40.82.146.87.sslip.io node scripts/upload-outline.mjs content/<경로>.md` (같은 제목이면 갱신, 없으면 생성. 제목이 키라서 제목을 바꾸면 새 문서가 생김)
- **사실만 쓴다. 부풀리지 않는다.** 근거 없는 수치·성과·직책을 쓰지 않는다. 확인 안 된 것은 질문하고, 모르면 빼는 게 원칙.
- **긍정적 표현**: "~는 아니었다" 같은 부정형 서술을 피하고 한 일을 쓴다(예: SBD는 "사업 수행과 관리").
- **약점·보안 사고 서술 금지**(시크릿이 저장소에 있었다, 토큰이 평문이었다 등). 설계한 내용만 쓴다.
- 고객사: S전자(삼성 표기 금지), 내부 IP·호스트명·비밀번호 금지. 정산 단가 같은 내부 수치와 조직명은 쓰지 않는다.
- AI 활용 여부는 문서에 쓰지 않는다. 꾸민 문구(오글거리는 표현)를 피하고 담백하게 쓴다.
- 질문은 적게, 구체적으로. 기억 안 나는 항목은 비워 둔다.

## 4. 한영 전환 구조

- 영어 문서는 별도 Outline 문서로 올리고 frontmatter에 `lang: "en"`을 둔다. slug는 한국어와 같게 유지하면 전환 버튼이 짝 문서로 이동한다.
- 경로: `/en/...`. Caddy `routes.Caddyfile`에 `/en*` 라우트. 영어 홈은 `config/site/index.en.html`.
- 번역 기준은 `docs/translation-guide.md`(용어집·다이어그램 규칙). 번역은 에이전트에게 맡기고 결과를 린트(한글 잔존, 코드펜스, lang, 내부 링크)한 뒤 올렸다.
- 영어 내부 링크는 `/en/projects/<slug>` 형식.
- 정적 백업(`scripts/build-static.mjs`)은 `content/en`을 제외한 한국어 전용.

## 7. 사실 확인이 필요하다고 표시해 둔 항목

- 부천 CSMS: 코드 상태값 `AMBIGUOUS_INOUT`를 "입출차 매칭이 모호한 건"으로 해석해서 서술. 인수인계(후임 대상)는 아직 진행 중이라 문서에 없음.
- 야구 게임: "친구들과 베타 사용 단계", 라이선스 방침("서비스가 커지면 정식 검토, 안 되면 가상 리그 전환") 문장이 들어 있음.
- Umpire 통합: "실제 조직이 운영 중"이라는 서술 외에 사용 인원·기간 수치는 없음.
- S3 Work Note: "RSA로 암호화, 읽는 쪽은 대칭키로 복호화"는 사용자 기억을 그대로 옮긴 것. 실제 구성(KMS 데이터 키 + RSA 등)이 확인되면 정확하게 고칠 것.
- RFQ: 원가 산정 담당 팀이 어디인지 불명이라 "원가 산정 담당 팀"으로 서술.
- 이노트리 삼성전자 앱스 "유지보수 연장계약" 성과는 사용자가 본인 성과가 아니라고 해서 제외.
