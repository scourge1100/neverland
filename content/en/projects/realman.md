# RealMan Tailor — Tailor Shop Booking Service

## Overview

A team project planned for users who need a suit for a wedding, a job interview, or another important occasion, so they can find a professional tailor and arrange a consultation and booking.

## Service Direction

- Browsing tailor shops and products
- Connecting users to the tailor they want through a booking
- Writing posts and viewing post details
- User authentication and service data management

## Role

I joined as a full-stack team member working on both the frontend and the backend. In a structure where the screens and the API are separate, I gained experience connecting user flows with the data contract.

## Technology

### Frontend

- Next.js 15
- React 19 / TypeScript
- Tailwind CSS
- React Hook Form / Zod
- Zustand

### Backend

- Java / Spring Boot
- Spring Security / OAuth2 / JWT
- Spring Data JPA / MyBatis
- PostgreSQL

## What I Learned

In a real project structure, I experienced how a team aligns screens with the API contract, how user flows that require authentication work, and how to decide the responsibilities of the frontend and the backend.
