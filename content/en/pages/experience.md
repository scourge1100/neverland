# Experience Built Through Projects

## Backend Platform

Designed and developed a Spring Boot based Core platform for the membership, authentication, permissions, and operations features shared by multiple services. Policy scope is separated by service type, and data changes are managed with PostgreSQL, JPA, and Flyway.

## Mobile Product

Developed an umpire operations app with React Native and Expo, and run the Android APK and OTA updates. Implemented, together with the API, the connected flow of real work: role-based assignments, announcements, game reports, settlement, and push notifications.

## Full-stack Web

Took part as a full-stack developer in a tailor shop team project built with Next.js and Spring Boot. Gained experience dividing responsibilities between the user-facing screens and the authentication and data APIs, and connecting them.

## Operations and Automation

I look at what comes after the feature is built: deployment, data migration, log diagnosis, and whether backup and recovery are possible. Repeated checks and deployment tasks are moved into scripts and CI/CD, and the operational evidence is documented so that problems can be reproduced.

## Working principles

- Judge based on actual code, data, logs, and execution results.
- Check service boundaries and the impact of a change first.
- Leave logs and diagnostic information so that failures can be observed.
- Verify until the system is actually usable, not just until the deployment succeeds.
