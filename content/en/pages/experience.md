# Experience Built Through Projects

I have worked mainly on Java and Spring backend development. Below is my work at each company, most recent first, with links to the project write-ups where they exist.

## Chaeum Solution · 2025.10 — 2026.02

On a project-based contract, I took part in building the GS E&C project management system (PMX). My work covered backend API development in Java and Spring, analysis of the existing system, query and processing logic on Oracle DB, and reflecting business users' requirements.

- [GS E&C Project Management System Build](/en/projects/gs-engineering-pmx): converted a procedure-centered MSSQL solution to Oracle PL/SQL and connected it to an iFrame-based integration

## Signetics · 2023.01 — 2025.04

On the IT team of a semiconductor manufacturer, I developed and maintained Java-based web systems. Most of the work was building large-scale data processing and analysis systems on Oracle, and I analyzed customer requests to propose a development direction.

- [MRB (Material Review Board) Issue Management System](/en/projects/mrb-issue-system): tracks material issues and meeting minutes by case, with code-based charts (2023.05 — 2023.10)
- [OCAP Quality Anomaly Response System](/en/projects/ocap-system): dashboards for process anomaly data and a daily automatic email report (2023.11 — 2024.04)
- [Asset Impairment Loss System](/en/projects/asset-impairment-system): automated impairment entry and depreciation recalculation (2024.02 — 2025.04)
- [CoA Data Collection & Validation System](/en/projects/coa-quality-system): SFTP collection, validation and approval of supplier quality data (2024.05 — 2024.12)
- [RFQ Digitization](/en/projects/rfq-foundation): a new foundation on Java 17 and Spring Boot instead of the legacy system (2024.12 — 2025.04)

## Rogue Wave · 2021.11 — 2022.11

I built a web-based admin tool on an AWS three-tier architecture using the eGovFrame framework. I implemented AWS service features with the AWS Java SDK, and after the game launched I handled maintenance, new features, system monitoring, and incident response.

- [YKW — Game Operations Admin Tool](/en/projects/yeolhyeolgangho-admin-tool): game operations data management and operational features such as item grants
- [Sending Text to the Game Server Safely: S3 and Encryption](/en/writing/encrypted-text-delivery-s3): notes on a small feature delivered with S3 and encryption

## Innotree · 2019.12 — 2021.10

I worked mainly on commissioned project work, in planning and operations. I analyzed customers' needs, made proposals to reach results, and then carried out the planning.

## BZ System · 2018.11 — 2019.10

## Working principles

- Make decisions based on real code, data, logs and run results.
- Check service boundaries and the impact of a change first.
- Leave logs and diagnostic information so that failures can be observed.
- Verify that the system is actually usable, not just that the deploy succeeded.
